# Portfólio — Claudimery Silva

Site estático, sem build. Suba estes arquivos na raiz do repositório e importe no Vercel (Framework Preset: **Other**).

- `index.html`: página de escolha com os 5 modelos
- `modelo-1-pedido.html` … `modelo-5-pessoal.html`: os modelos
- `preview-1.jpg` … `preview-5.jpg`: imagens de prévia usadas na página de escolha
- `foto.jpg`, `favicon.svg`, `curriculo.pdf`: arquivos usados por todos os modelos

## Depois de escolher o modelo

1. Apague o `index.html` atual (a página de escolha).
2. Renomeie o modelo escolhido para `index.html`.
3. Nesse arquivo, apague a linha do botão "← Todos os modelos" (perto do fim, marcada com um comentário).
4. Apague os outros modelos e os arquivos `preview-*.jpg`.
